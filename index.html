Viewing it locally

Opening this file directly works for every page. To get the 3D model and fonts exactly as published, serve the folder instead:

python3 -m http.server 8080
# then open http://localhost:8080

To rebuild the HTML and PDF copies after editing a Markdown file or a slide, run python3 tools/build.py --pdf (needs pip install markdown and Google Chrome).
